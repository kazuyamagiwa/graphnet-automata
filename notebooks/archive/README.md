# Archived notebooks (NetworkX 2 era)

Frozen snapshots of the exploratory Jupyter notebooks **as they existed before the NetworkX 3 migration**.

These files are kept for historical reference and reproducibility against the original Colab / Anaconda-era stack (NetworkX 2.x APIs such as `nx.to_numpy_matrix` / `nx.from_numpy_matrix`).

- **Do not edit** files here unless you intentionally need a historical patch.
- Active, maintained notebooks live in the parent [`notebooks/`](../) directory and target NetworkX 3+.

Archived on the uv project restructure / NetworkX 3 update.
